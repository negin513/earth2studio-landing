# Examples

Runnable, self-contained inference workflows — the fastest way to learn
Earth2Studio by doing.

The example gallery covers the core patterns:

- **Deterministic forecasting** — single-model global forecasts
- **Ensemble forecasting** — perturbation methods and GPU-parallel members
- **Diagnostics** — derived variables and downscaling on top of forecasts
- **Data handling** — fetching, caching, and IO to Zarr and NetCDF
- **Model-specific workflows** — per-model guides across the zoo

Each example is a single Python script you can run directly, with the
generated plots shown inline in the gallery.
