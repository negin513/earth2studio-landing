# User Guide

Earth2Studio is an AI inference pipeline toolkit for weather and climate
applications. It rides on top of different AI frameworks, model architectures,
data sources, and SciML tooling while providing one unified API.

Start with any of the sections below, or jump straight to the
[official documentation](https://nvidia.github.io/earth2studio/) for install
guides and the full API reference.

<div class="grid cards" markdown>

- 🧠 **[Models](models.md)** — the prognostic and diagnostic model zoo
- 🌐 **[Data](data.md)** — reanalysis, operational, and observation sources
- 🔁 **[Workflows](workflows.md)** — what you can build with the pipeline blocks
- 🧩 **[Ecosystem](ecosystem.md)** — Earth-2, PhysicsNeMo, and interoperability
- ✅ **[Verification](verification.md)** — metrics for trusting your forecasts

</div>

## Install

```bash
pip install earth2studio
```

See the [install guide](https://nvidia.github.io/earth2studio/userguide/about/install.html)
for model-specific extras and GPU requirements.
