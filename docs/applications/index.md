# Applications

What you can build from Earth2Studio's composable pipeline blocks.

## Global medium-range forecasting

Run state-of-the-art AI forecast models on demand. Forecasts that once
required a supercomputing center complete in seconds to minutes on a single
NVIDIA GPU.

## Probabilistic and ensemble prediction

GPU-parallelized ensembles with built-in perturbation methods quantify
forecast uncertainty — the foundation for risk-based decision making in
energy, insurance, logistics, and agriculture.

## Downscaling and impact variables

Diagnostic models turn coarse global fields into high-resolution,
decision-ready outputs: precipitation estimates, regional km-scale detail,
derived weather variables.

## Extreme event analysis

Track cyclones, analyze severe weather, and study high-impact events using
diagnostic tooling and observation records like IBTrACS.

## Research and model intercomparison

Benchmark models against each other on identical data behind one API — a
level playing field for evaluating new architectures, and a fast prototyping
surface for new pipeline ideas.
