## Suggested learning path

1. **Install** — `pip install earth2studio` and run the quick-start snippet
2. **First forecast** — the deterministic workflow example with SFNO + GFS
3. **Go probabilistic** — ensemble examples with perturbation methods
4. **Add diagnostics** — derived variables and downscaling
5. **Verify** — score your forecasts with the built-in metrics suite
6. **Scale up** — graduate to the recipes: HENS, S2S, cyclone tracking
